==================================================
PRODUCT DEFINITION
==================================================

The product is a Smart Waste Management / Recycling Ecosystem for universities.

The system connects:

1. University Students
2. Smart Recycling Machines
3. University Administration
4. Recycling / Operations Team

The mobile application is primarily for university students.

The smart machine receives recyclable waste, identifies its category, sorts it, compresses it, and stores it in the correct compartment.

There are exactly THREE core waste categories:

1. METAL / CANS
   Examples: beverage cans and metal cans.

2. PLASTIC
   Examples: plastic water bottles and plastic containers.

3. PAPER / CARDBOARD
   Examples: paper and cardboard.

The user does NOT manually choose the waste category.
The machine performs the classification.

Core recycling flow:

Find Machine
→ Select Machine
→ Navigate to Machine
→ Identify User
→ Insert Waste
→ Machine Detects
→ Machine Classifies
→ Machine Compresses
→ Transaction Verified
→ Recycling Successful
→ Points Added
